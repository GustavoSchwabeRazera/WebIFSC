O que é JavaScript?

A motivação para a criação do JavaScript

O JavaScript foi criado em 1995 pela Netscape, a pedido da empresa, com o objetivo principal de tornar as páginas da web dinâmicas e interativas, já que na época a internet era composta por páginas totalmente estáticas de HTML.

A diferença entre execução no navegador e no servidor

A diferença essencial é que o JavaScript no navegador atua no front-end, controlando a interface visual e a interatividade da página dentro de um ambiente seguro e restrito (sem acesso ao computador do usuário), enquanto no servidor ele roda no back-end (via Node.js), tendo acesso total ao sistema operacional para manipular arquivos, conectar-se a bancos de dados e gerenciar a lógica de bastidores do sistema.

O conceito de sandbox no navegador

O conceito de sandbox (caixa de areia) no navegador é um mecanismo de segurança que isola a execução de códigos e scripts de páginas web do restante do sistema operacional do usuário. Ele funciona como uma barreira protetora que impede que sites maliciosos consigam acessar seus arquivos pessoais, instalar vírus ou controlar o seu computador.

Objetos globais como document, console e alert.

Estes objetos globais são as ferramentas nativas que o ambiente do navegador injeta no JavaScript para permitir a comunicação com a página, com o desenvolvedor e com o usuário.

  1. document: é o objeto que representa a página web carregada no navegador, permitindo acessar e manipular elementos HTML, como textos, imagens, links e formulários.
  2. console: é o objeto que fornece uma interface para o desenvolvedor interagir com o código JavaScript, permitindo exibir mensagens de depuração, erros e informações no console do navegador.
  3. alert: é o método que exibe uma caixa de diálogo com uma mensagem para o usuário, sendo útil para notificações simples ou testes rápidos.
