O que é HTTP?

O HTTP (Hypertext Transfer Protocol) é o protocolo usado para a comunicação entre o navegador (cliente) e um servidor Web. Quando acessamos um site, o navegador envia uma requisição HTTP (request) pedindo algum recurso. O servidor recebe o pedido e devolve uma resposta HTTP (response), que pode conter HTML, imagens, dados e outros arquivos.

Como é usado na web?

O HTTP é usado para solicitar e enviar dados entre um navegador web e um servidor web. Quando você acessa um site, seu navegador envia uma solicitação HTTP ao servidor, que responde com os dados solicitados, como páginas HTML, imagens, scripts e outros recursos.

Exemplo Requisição:

GET /index.html HTTP/1.1
Host: exemplo.com
User-Agent: Mozilla/5.0
Accept: text/html
Accept-Language: pt-BR

Os principais campos são: GET, que indica o método utilizado; Host, que identifica o servidor; User-Agent, que informa características do navegador; Accept, que indica os tipos de conteúdo aceitos; e Accept-Language, que informa os idiomas preferidos.

Exemplo Resposta:

HTTP/1.1 200 OK
Content-Type: text/html
Content-Length: 1234

<!DOCTYPE html>
<html>
<head>
<title>Exemplo</title>
</head>
<body>
<h1>Bem-vindo ao Exemplo</h1>
<p>Este é um exemplo de página web.</p>
</body>
</html>

200 OK significa que a requisição foi realizada com sucesso. Content-Type informa o tipo do conteúdo retornado, como text/html. Content-Length informa o tamanho da resposta em bytes e Server pode fornecer informações sobre o software do servidor.
