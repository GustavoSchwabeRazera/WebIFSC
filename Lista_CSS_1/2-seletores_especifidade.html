A especificidade do CSS define qual regra será aplicada quando várias regras podem atingir o mesmo elemento. A ordem de prioridade, de forma geral, é: ID > classe/atributo > elemento. No exemplo, cada item recebe uma cor de acordo com a regra mais específica que corresponde a ele. O li aplica uma cor básica, enquanto classes como .fruta e .churras são mais específicas. Seletores com ID, como #lip2, têm prioridade maior. Quando combinamos seletores, como #lip3.fruta ou .churras[draggable="true"], a especificidade aumenta. A regra li+li.churras também considera a posição do elemento, selecionando um li que vem imediatamente depois de outro li e possui a classe churras. Já a regra ol>li.churras#lip5 não é aplicada porque não existe nenhum elemento com o ID lip5. Portanto, o navegador sempre verifica quais regras correspondem ao elemento e aplica a que possui maior especificidade.
