## ▶️ Como executar

**HTML, CSS e JavaScript:** basta abrir qualquer arquivo `.html` no navegador, ou acessar o [site publicado](https://gustavoschwaberazera.github.io/WebIFSC/).

**PHP:** os arquivos `.php` precisam de um servidor PHP (o GitHub Pages não executa PHP). Com o PHP instalado, rode na raiz do projeto:

```bash
php -S localhost:8000
```

E acesse, por exemplo, `http://localhost:8000/Lista_PHP/7.php`.
